# open-career

Working repository for the open-career build: a local-first job-application system pairing a
local backend with a Chromium extension that fills application forms and stops, so that a human
performs every submission. The repository name is the scope id, not the public product name,
which is still undecided. Design decisions live in the scope ledger at
`../DECISIONS.md`; this repo carries only code.
